# Sample shop

A tiny web shop used to try Explicador: a login form, an auth API with password hashing and sessions, and a cart that needs a session. No dependencies; `npm start` serves it on http://127.0.0.1:3000 (demo user `ada@example.com` / `lovelace`).

Try, from this folder:

```sh
claude --plugin-dir ../..
> /explicador:explain login
```
